## Frontend API contract
GET /api/v1/explorer?version=latest&family=&material_form=&status=formal responds {version,scope:{family,material_form,status},options:{families:string[],material_forms:string[],versions:string[]},summary:{samples,doi,families,projected},points,axes,family_colors,charts}. points per point_cloud.py: sample_id,doi,family,plot_family,formula,material_form,PC1/2/3,emission_nm,available_fields,total_fields,coverage_fraction,coincident_count (plus status). axes:{key,explained_variance_ratio,min,max,top_loadings}. charts.emission:{grid:number[],groups:[{name,color,n,median,min,max,density:number[],points:[{sample_id,x}]}],histogram:[{left,right,count}],ecdf:[{x,y}]}; charts.relationship:{x_label,y_label,points:[{sample_id,x,y,family,color}],x_grid:number[],y_grid:number[],groups:[{family,color,density_x:number[],density_y:number[]}]}; charts.quality:{fields:string[],rows:[{sample_id,family,available:boolean[]}],coverage:[{field,count,total}],sources:[{source,count}]}; charts.evidence:{families:[{family,samples,doi,series}],papers:[{doi,samples}]}; charts.correlation:{labels:string[],values:[{i,j,r:number|null,n}]}; charts.readiness:[{model,ready,total}]. records array all filtered samples for drawer/CSV, fields sample_id,doi,family,formula,material_form,emission_nm,status,available_fields,total_fields,coverage_fraction; points only eligible projection. Missing charts arrays empty + true messages.
